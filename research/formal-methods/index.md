# Formal Methods

We study new ways of combining signal temporal logics and epistemic logic to design verified multi-agent planning frameworks.

Topics include:

- Motion planning for swarms using temporal logic & epistemic logic specifications
- Distance between formulae constructed using temporal logic & epistemic logic 
- Guaranteeing coverage of secure areas with UAV swarms monitored using formal specifications  
- Guaranteeing against the emergence of potential multi-agent behaviours
